# ГРАБИТЬ КОРОВАНЫ

> «Здраствуйте. Я, Кирилл. Хотел бы чтобы вы сделали игру, 3Д-экшон суть такова...»
> — Кирилл, который джва года ждал

Полноценный браузерный 3Д-экшон по спецификации Кирилла (`SPECIFICATION.txt`). Всё процедурное: модели, звук, музыка.

## Запуск
```bash
npm install
npm start        # соберёт и откроет http://localhost:4173
# или для разработки:
npm run dev
```

## Что есть (по пунктам ТЗ)
- **Три стороны:** лесные эльфы, охрана дворца, Злой (имя так и не придумали).
- **Эльфы:** густой лес, деревянные домики и дома на деревьях; солдаты дворца и войска Злого **набигают**; вождь даёт задания.
- **Можно грабить корованы:** повозки с лошадьми ездят по дорогам с охраной; перебейте охрану и жмите **E**.
- **Лес как просил Кирилл:** вдали деревья — картинкой (билборды, отрендеренные с 3Д-модели), вблизи превращаются в 3Д-деревья.
- **Покупать как в Daggerfall:** 7 лавок, торг, продажа добычи, лекарь-протезист, таверна, жалованье.
- **Враги 3Д, трупы 3Д:** трупы остаются лежать, их можно обыскать.
- **Можно прыгать** (Пробел).
- **Охрана дворца:** слушайтесь командира — посты, патрули, ловля шпионов, оборона, набеги; звания от рядового до капитана; за непослушание — в дезертиры.
- **Злой:** сам себе командир (**C**) — вербуйте войска и ведите их на дворец; шпионы и партизаны иногда нападают на форт.
- **4 зоны:** люди (нейтрал), император (дворец), эльфы, Злой (горы, старый форт).
- **Отрубить руку** → кровотечение, если не вылечат — смерть. **Выколоть глаз** → пол экрана не видно (или стеклянный глаз). **Нога** → либо умрёшь, либо ползать, либо коляска, либо — самое хорошее — протез.
- **Сохранятся можно:** F5/F9, слоты, автосохранение.

## Управление
WASD — ходить, Shift — бег, Пробел — прыжок, ЛКМ — удар (взгляд вверх — по голове, вниз — по ногам), ПКМ — блок,
E — действие, V — вид от 1-го/3-го лица, X — коляска, I/Tab — инвентарь, M — карта, J — журнал, C — командование, Esc — пауза.

*Посвящается Кириллу.*
